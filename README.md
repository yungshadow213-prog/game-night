# Game Night 3.0.6

Private two-player Game Night app.

Highlights in this build:
- Locked master interface; only interaction areas were refined.
- Draw & Guess Live canvas with pen, eraser, adjustable boldness, colors, custom color, undo, redo, clear and live sync.
- Game controls: Refresh, Skip question and End game during active play.
- End game returns both players to the private room so another game can be selected.
- WhatsApp-style rounded chat composer with emoji tray, timestamps, typing status and quick reactions.
- In-site PWA install entry in Settings with browser/device fallback guidance.
- Versioned service worker cache.

Run:
```
npm install
npm start
```
