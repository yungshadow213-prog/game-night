# Game Night — Final Build

A private, real-time, two-player Game Night web app/PWA.

## Included
- Exactly 2 players per private room
- Room code joining
- Editable display name and avatar
- Private persistent-in-room chat across lobby and games
- 3/5/7/10 rounds + Quick Play mode
- Would You Rather, How Well Do You Know Me?, Guess My Answer, Couple Quiz, Truth or Dare — Lite, Flirty / Teasing
- Server-authoritative scoring with +10 base and streak bonuses (+15, +20, +25...)
- Shared streak, best streak, games together, shared points
- Random Date Night generator
- Romantic / phonk / off audio modes using browser-generated cues (no copyrighted recordings bundled)
- Classic, Chaos, and Quick Play modes
- Installable PWA shell
- Responsive phone/tablet/desktop UI
- Reconnect/disconnect room handling

## Run locally
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

For the two of you to use it without running code, deploy this folder to a Node-compatible host such as Render. After deployment, share the HTTPS link and room code.
